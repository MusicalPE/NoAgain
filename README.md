# 주또싫 — 주원이는 또 틀리기 싫어요

줄 노트에 손글씨로 쓴 느낌의 오답노트입니다.
틀린 문제를 사진으로 찍어 모으고, 비슷한 문제로 다시 풀고, PDF 시험지로 뽑는 전 과목 오답노트 웹앱입니다.

- 사진 속 문제·내 답·정답·채점 표시를 AI가 읽어 정리 (도형·그래프는 잘라서 함께 저장)
- 같은 유형의 비슷한 문제 자동 생성
- 틀린 문제만 모아 다시 풀기 (맞히면 익힘으로)
- A4 시험지 + 정답·풀이 PDF 출력
- Google 로그인, QR 초대로 가족이 같은 노트를 함께 쓰기

GitHub Pages(또는 Firebase Hosting) + Firebase(Authentication, Firestore, AI Logic, App Check)로 동작합니다.
