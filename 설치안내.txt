주또싫 (주원이는 또 틀리기 싫어요) 설치 안내
=============================================

사진을 찍어 올리면 AI가 문제를 정리하고, 비슷한 문제를 만들어 주고,
틀린 문제만 모아 다시 풀거나 PDF 시험지로 뽑는 웹앱입니다. 과목 제한은 없습니다.

준비물: 구글 계정, GitHub 계정


1단계. 파이어베이스 프로젝트 만들기
------------------------------------
1) https://console.firebase.google.com 에서 [프로젝트 추가]
2) 이름 예: jutto-sil  (Google 애널리틱스는 꺼도 됩니다)


2단계. 웹 앱 등록하고 설정값 복사
------------------------------------
1) 프로젝트 개요 옆 톱니바퀴 > 프로젝트 설정 > 내 앱 > 웹(</>) 아이콘
2) 앱 닉네임을 적고 등록 (Firebase 호스팅은 체크하지 않음)
3) 화면에 나오는 firebaseConfig 의 값 6개를
   config.js 의 FIREBASE_CONFIG 에 그대로 옮겨 적기


3단계. 구글 로그인과 데이터베이스 켜기
------------------------------------
1) 빌드 > Authentication > 시작하기 > 로그인 방법 > Google > 사용 설정
2) Authentication > 설정 > 승인된 도메인 에
   MusicalPE.github.io 처럼 GitHub Pages 주소(앞부분)를 추가
3) 빌드 > Firestore Database > 데이터베이스 만들기
   - 위치: asia-northeast3 (서울)
   - 프로덕션 모드로 시작
4) Firestore > 규칙 탭에 "파이어베이스-규칙.txt" 내용을 통째로 붙여 넣고 [게시]


4단계. AI 기능 켜기 (Firebase AI Logic)
------------------------------------
1) 왼쪽 메뉴 AI 서비스 > AI Logic > 시작하기
2) Gemini API 제공자는 "Gemini Developer API" 선택 (무료로 시작 가능)
3) 안내에 따라 끝까지 진행


5단계. App Check 연결 (AI를 쓰려면 꼭 필요)
------------------------------------
AI Logic 을 켜면 App Check 가 자동으로 켜집니다.
App Check 가 없으면 남이 내 AI 사용량을 몰래 쓸 수 있어서 막아 두는 장치입니다.

1) 파이어베이스 콘솔 > App Check > 앱 탭에서 내 웹 앱 선택
2) 제공자로 reCAPTCHA Enterprise 를 고르고, 안내에 따라 사이트 키를 만들기
   - 도메인에 GitHub Pages 주소(예: musicalpe.github.io)를 넣기
3) 만든 사이트 키를 config.js 의 RECAPTCHA_SITE_KEY 에 붙여 넣기

  내 컴퓨터(localhost)에서 시험할 때는 "디버그 토큰"이 브라우저 콘솔에 찍힙니다.
  그 값을 App Check > 앱 > 디버그 토큰 관리 에 등록하면 됩니다.


6단계. GitHub 에 올리기
------------------------------------
1) GitHub 에서 새 저장소 만들기 (이름 예: jutto-sil, Public)
2) 이 폴더의 파일을 모두 올리기
   index.html, app.js, config.js, style.css, manifest.webmanifest, icon.svg
   (이 안내 파일과 규칙 파일은 올려도 되고 안 올려도 됩니다)
3) 저장소 Settings > Pages > Branch 를 main / (root) 로 저장
4) 1~2분 뒤 https://아이디.github.io/저장소이름/ 로 접속

  참고: config.js 에 들어가는 파이어베이스 값은 공개되어도 괜찮은 값입니다.
  실제 보호는 3단계의 규칙과 5단계의 App Check 가 맡습니다.


7단계. 휴대폰에 앱처럼 깔기
------------------------------------
- 안드로이드(크롬): 주소 접속 > 메뉴(⋮) > 홈 화면에 추가
- 아이폰(사파리): 주소 접속 > 공유 > 홈 화면에 추가


앱 이름 바꾸기
------------------------------------
config.js 의 APP_NAME(짧은 이름), APP_SUBTITLE(긴 이름)을 바꾸면 화면과 시험지에 함께 바뀝니다.
홈 화면에 깔리는 이름은 manifest.webmanifest 의 name, short_name 에서 바꿉니다.


쓰는 방법
==================
1) 처음 로그인하면 오른쪽 위 [설정]에서 학년을 적어 두세요. AI가 눈높이를 맞춥니다.
2) [찍기] 채점한 문제지를 찍고 [문제 읽기]
   - 틀린 문제에 자동으로 체크됩니다. 글·정답·풀이를 확인하고 고칠 곳은 고치세요.
   - 도형·그래프가 있는 문제는 그 부분이 자동으로 잘려 들어갑니다.
     잘못 잘렸으면 [그림 다시 자르기]로 손가락으로 네모를 그려 고릅니다.
   - [체크한 문제 저장]을 누르면 문제마다 비슷한 문제가 2개씩 같이 만들어집니다.
3) [오답 모음] 과목별로 보기, 찾기, 고치기, 비슷한 문제 더 만들기
4) [다시 풀기] 오래 안 푼 문제·많이 틀린 문제부터 골라서 냅니다.
   - 두 번 연속 맞히면 "익힘", 다시 틀리면 틀린 횟수가 올라갑니다.
   - 답을 다르게 썼을 뿐 같은 답이면 [맞았어]를 눌러 바로잡을 수 있습니다.
5) [뽑기] 조건을 고르고 [PDF 만들기] > 인쇄 창에서 "PDF로 저장"
   - A4 두 단 시험지, 맨 뒤에 정답·풀이 쪽이 붙습니다.


알아 둘 점
==================
- AI가 만든 문제와 AI가 푼 정답은 가끔 틀릴 수 있습니다. "비슷한 문제", "AI가 푼 답"
  표시가 붙어 있으니 이상하면 [고치기]나 [지우기]로 정리해 주세요.
- 사진 원본은 저장하지 않고, 문제 글과 잘라 낸 그림만 저장합니다.
  (그래서 파이어베이스 무료 요금제 안에서 쓸 수 있습니다)
- 처음 로그인하면 내 노트가 하나 만들어집니다. [설정] > [QR로 초대하기]로 가족을 초대하면
  같은 노트를 함께 보고 채울 수 있습니다. 초대 QR은 하루 동안만 쓸 수 있습니다.
- 지인이 따로 들어오면 그 사람만의 노트가 새로 생깁니다. 초대하지 않은 사람의 노트는 보이지 않습니다.
- AI 무료 사용량은 이 파이어베이스 프로젝트 하나를 함께 씁니다.
  쓰는 사람이 많아지면 잠깐씩 "사용량이 넘쳤어요" 알림이 뜰 수 있습니다.
- AI 모델 이름이 바뀌어 AI가 동작하지 않으면 config.js 의 AI_MODELS 맨 앞에
  콘솔 AI Logic 화면에 나오는 최신 모델 이름을 넣어 주세요.
