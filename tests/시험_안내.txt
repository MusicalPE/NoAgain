올리기 전 시험 안내
===================

1. 단순 수정 (글귀, 색, 여백, 그림 교체)
   bash tests/run.sh code
   - 코드 검사만 해요: 문법 오류, 따옴표·괄호 짝(index.html · style.css · 파이어베이스 규칙),
     단추가 가리키는 화면 요소·동작·함수가 실제로 있는지, 판 번호가 파일마다 같은지,
     미리보기(demo) 모듈에서 가져오는 이름이 다 있는지

2. 기능 수정 (새 기능, 화면 배치 변경, 서버·저장 방식 수정)
   bash tests/run.sh full
   - 코드 검사 + 화면을 실제로 띄워 한 번씩 밟아 보기
     로그인 화면(사용 안내 단추) / 로그인 뒤 목록·통계 / 사용 안내 창(항목 9개, Esc·확인·바깥으로 닫기, 단추 높이) / 설정 / 사진 읽기 → 결과 보기 → 고치기 → 저장 /
     비슷한 문제(AI) + 문제 은행 저장 / 같은 유형은 은행에서 바로 / 다시 풀기 /
     맞은 답 바로잡기 / 시험지 뽑기(PDF) / 문제 지우기 / 식 읽는 규칙이 AI 안내에 들어감 /
     카드에서 해답지로 정답 넣기 / 사진 읽기 화면에서 해답지로 다시 채점 /
     중학생: 두 번 푼 답이 다르면 "확실하지 않아요" · 확인 안 된 틀은 은행에 안 넣음 · 정답 고르기 /
     무료 체험 끝 → AI 키 넣기 → 내 키로 AI /
     미리보기(?demo, 안에서는 미리보기 링크 숨김) / 화면 오류 없음
   - 파이어베이스와 AI 는 시험용 가짜로 바꿔 끼워서, 진짜 노트와 AI 사용량은 건드리지 않아요.

3. 어느 쪽인지 애매하면 full.
4. 하나라도 실패하면 올리지 않고 먼저 고쳐요.
5. 판 번호: 고칠 때마다 app.js 의 APP_VERSION, sw.js 의 VERSION, index.html 의 app-version 을 같이 올려요.
