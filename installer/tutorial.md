# 또싫 오답노트 설치하기

구글 계정 하나로 나만의 오답노트 앱을 만들어요. 15분쯤 걸리고, 비용은 들지 않아요.

만든 사람: 음악적체육인

## 처음 설치하기

1. 아래 회색 칸 오른쪽의 **복사하기 단추**(네모 두 개 겹친 모양)를 누르세요.
2. 아래쪽 **검은 화면을 한 번 누르고** 붙여 넣으세요. (Ctrl+V, 또는 마우스 오른쪽 단추 > 붙여넣기)
3. **Enter** 를 누르세요.

```bash
bash installer/install.sh
```

- 처음에 "Cloud Shell 승인" 창이 뜨면 **승인**을 누르세요.
- 아이 이름을 물으면 적고 Enter 를 누르세요. (예: 지민 → 지또싫 / 지민이는 또 틀리기 싫어요)
- 나머지는 도우미가 알아서 해요. 중간에 **직접 눌러야 하는 곳 두 군데**가 나오면,
  화면에 나오는 주소를 열어 안내대로 누르고 돌아와서 Enter 를 누르세요.
- 마지막에 **내 앱 주소**(https://ttosil-…web.app)가 나오면 끝이에요.

## 휴대폰에 앱처럼 깔기

마지막에 나온 내 앱 주소를 휴대폰에서 열고,

- 안드로이드(크롬): 메뉴(⋮) > **앱 설치** 또는 **홈 화면에 추가**
- 아이폰·아이패드(사파리): 공유 > **홈 화면에 추가**

처음 로그인한 뒤 [설정]에서 학년을 적고, [QR로 초대하기]로 아이 기기를 초대하면 같은 노트를 함께 쓸 수 있어요.

## 새 판으로 바꾸기 (나중에)

설치할 때 쓴 링크를 다시 열고, 아래 칸을 **복사하기 → 검은 화면에 붙여넣기 → Enter** 하세요. 넣어 둔 문제는 그대로 남아요.

```bash
git pull && bash installer/install.sh update
```

## 안 될 때

- 빨간 ✖ 표시와 함께 멈추면 화면을 캡처해서 만든 사람에게 보내 주세요.
- 다시 해 보고 싶으면 처음 설치 명령을 한 번 더 붙여 넣으면 돼요. (새 프로젝트가 하나 더 만들어져요)
